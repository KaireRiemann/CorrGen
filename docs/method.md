## 论文式 (8)、(9) 的 LP

令 `T_k(2u−1)` 为 Chebyshev 基，`u∈[0,1]`。五个标量多项式 a,b,c,d,e：

```
E(u) = [a(u) c(u); c(u) b(u)]
l(u) = [d(u), e(u)]ᵀ
q(u,w) = wᵀ E(u) w + l(u)ᵀ w − 1
corridor: q <= 0
```

所有五组多项式共享次数 n，共 `5(n+1)` 个变量。目标为在 N 个参数值上累加 `a+b`；障碍约束为在各自实际参数值处 `q >= exclusion_margin`，不是把每个点强行分配到最近采样格。默认 N=101、n=6、margin=1e−5。

用四个线性约束 `a±c >= ε`、`b±c >= ε` 表示严格对角占优，ε 默认 0.02。人工 wrapper 在每个采样参数处放置 24 个半径 3 m 的横截面点，限制无障碍区域的尺度。

目标是论文使用的 trace 代理，不等于直接最大化真实体积，因此不能断言次数增大时真实体积一定增大，也不能把它称为精确最大体积解。GLPK 系数中小于 1e−12 的数归零以消除 sin/cos 理论零点的舍入噪声，最终使用原始多项式重新检查障碍残差。

## 解析导数和椭圆几何

```
q_u  = wᵀ E_u w + l_uᵀ w
q_w  = 2Ew + l
q_uu = wᵀ E_uu w + l_uuᵀ w
q_uw = (2E_u w + l_u)ᵀ
q_ww = 2E
```

Chebyshev 基、一次和二次导数通过递推同时计算，不在 u=0/1 用 acos 的奇异导数。所有导数是对归一化 u，不是对弧长。世界坐标优化需再对参考路径/坐标变换使用链式法则；本库没有伪称直接返回世界坐标 Hessian。

中心 `h=−E⁻¹l/2`；完成平方后的尺度 `r=1+hᵀEh`。若 E 的特征值为 λ，半轴为 `sqrt(r/λ)`，截面积为 `πr/sqrt(det E)`。忽略 r 会错误地绘制偏心椭圆。

## 相比论文和上游的明确差异

1. 上游 LP 仅使用 `a≥c,b≥c`。负 c 时不保证正定。本实现使用正负两侧严格占优。
2. 上游在离散路径上找最近点，可按切向残差剪除点。本实现对三次参考的 `(p−γ(u))ᵀγ'(u)=0` 五次多项式枚举全部实根，约束所有横截面交点，避免只取最近投影遗漏另一截面。直线路径外端点没有横截面交点，计入 `outside_finite_sweep`，不是不可行的端点障碍。
3. 对每个 `a±c,b±c`，转换为 Bernstein 系数并用 de Casteljau 递归分割，对整个区间作凸包下界检查。它比密集采样强，但使用 long double 浮点计算，不是有向舍入的形式化区间证明。高阶/病态系数可能认证失败；失败不输出成功走廊。
4. 参考路径为常规三次 Bézier，不是论文 PH 曲线。当前交互适配器使用分段三次 B-spline，不再要求 x 递增；通过整条路径共同的参考轴以及每段切向非退化检查建立标架。走廊核心可以接受其他参考提供的 Occupancy。
5. 实现论文的 LP 路线，未实现 SDP 或单独的 2D 上下界 LP；不声称完全重现论文所有实验。
6. `area_arclength_integral` 是截面积乘参考弧长的数值积分，不是存在弯曲、自交时世界坐标并集的精确体积。

## A* 与安全范围

ROS demo 使用三维占据体素和 26 邻域 A*，检查对角移动涉及的中间体素，不限于平面图像地图。选点必须位于地图内自由体素。

对完整 A* 做可见性简化，再等距细分成统一三次 B-spline 控制序列。两端通过外推控制点精确保留；连接处的位置、一阶及二阶参数导数连续。若圆滑后的 Bézier 段包围盒与占据体素有交集，递归细分检查；若无法确认整条参考自由，细化控制序列后重试，最终失败则报告，不截短路径。

每段投影枚举实根后映射到全局 u∈[0,1]，所有交点一起约束同一组 Chebyshev 系数。局部坐标走廊函数 q(u,w) 是全局多项式，至少 C²；参考中心线 C²，由其切向构造的世界标架保证 C¹，不宣称世界坐标参数曲面在接头处也有连续二阶导数。这里未生成带时间、速度或加速度约束的轨迹。

碰撞约束针对输入点中心，未覆盖点间表面、体素实体、动态障碍或机器人半径；q 的正裕量没有米的含义。wrapper 也是有限采样点，不保证走廊严格落在地图边界内。实际机器人应用需要实体障碍建模、膨胀/净空认证和更一般路径表示，这些尚未实现。

正定确保每个横截面是有界椭圆且参数约束光滑；不保证整个世界坐标管道无自交或坐标映射全局一一对应。
